# オルゴラッシュ（OrgoRush）

構造式を見分ける、有機化学のクイズアプリです。見分けて、覚えて、もう1問！

**▶ 遊ぶ： https://koichem.github.io/OrgoRush/**

## 内容

- 高校有機化学の **121化合物** が対象（データは [OrgoBingo](https://github.com/KoiChem/OrgoBingo) の化合物データを使用）
- モード
  - **四択ラッシュ**：構造式・名前・性質から答える10問クイズ
  - **見比べラッシュ**：まぎらわしい2つを見比べて選ぶ
  - **ペアリングラッシュ**：構造式と名前の正しいペア（ワンペア／ツーペア）をさがす
  - **苦手だけ復習**、あと1問リベンジ
- **CHEM BOOST!**：正解した化合物ごとに、発展ポイントが図鑑で開きます
- **CHEM STORY**：化合物にまつわる読み物も図鑑で読めます
- 学習記録はブラウザ内（localStorage）に保存されます
